PixelDot2D Core Framework Patch Notes History — 4.0+

Full Patch Note History for the PixelDot2D Core Framework, beginning with Version 4.0.

**Available on the:** [Unity Asset Store](https://assetstore.unity.com/packages/tools/utilities/pixeldot2d-core-framework-370674)



> [!IMPORTANT]
Version 4.0 represents a major architectural milestone for the PixelDot2D Framework. This release introduces significant framework refactoring, new modular systems, performance improvements, new combat architecture, data-driven character animation, crafting, merchants, and multi-currency economy support. Due to the scale of these changes, the patch-note history has been separated from the pre-4.0 release history. This document will serve as the primary patch-note archive for Version 4.0 and all future releases.

> [!NOTE]
Looking for previous releases? The complete patch-note history for Versions 2.x–3.x [is available here.](https://github.com/PixelDot2D/PixelDot2D-Core-Framework-Patch-Notes-History-Pre-4.0) Version 4.0 marks the beginning of the framework's next major architectural phase.
